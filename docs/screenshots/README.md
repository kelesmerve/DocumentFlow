# Ekran görüntüsü rehberi

Ekran görüntülerini çalışan Development uygulamasından, [demo senaryosundaki](../demo.md) gerçek kayıtlarla alın. Örnek belgelerde kişisel/kurumsal gizli veri kullanmayın; JWT, parola, webhook secret, özel anahtar, tarayıcı geliştirici araçları ve bağlantı dizelerini kadraja almayın. Aynı pencere genişliği ve okunabilir yakınlaştırma kullanın; dosyaları bu dizine aşağıdaki adlarla kaydedin.

| Dosya adı | Gösterilecek ekran |
| --- | --- |
| `01-giris.png` | Giriş formu, kimlik bilgileri doldurulmadan |
| `02-dashboard.png` | Dashboard ve özet kartları |
| `03-belgeler.png` | Belge listesi ve durumlar |
| `04-belge-detay.png` | Belge detayı, versiyon geçmişi ve Süreç sekmesi |
| `05-onay.png` | Manager onay listesi veya karar dialogu |
| `06-imza.png` | Dijital imza kaydı ve doğrulama sonucu |
| `07-mobil-imza.png` | Simülasyon uyarısı ve bekleyen talep |
| `08-audit.png` | Admin İşlem Geçmişi ve filtreler |
| `09-entegrasyonlar.png` | Admin webhook listesi ve teslimat durumları |

Görüntüler gerçekten eklenmeden README'ye görsel bağlantısı koymayın. Mobil görünümü göstermek isterseniz aynı ekranlardan ayrıca dar ekran görüntüleri alın; tasarım değişikliği veya sahte kayıt üretimi gerekmez.
